# chaoxing-autoplay

**超星学习通 / 珞珈在线 / 智慧珞珈 —— 课程视频自动静音连播**

通过 Chrome DevTools Protocol（CDP）远程控制你本机**真实已登录的谷歌浏览器**，自动逐节打开课程视频、静音播放，播到 **98%**（默认，即「只剩最后 2%」）后自动切下一节；默认**跳过已经完成的章节**，直接从你还没看过的那一节开始。

纯 Node 脚本，**不依赖 WorkBuddy**，在 Codex / Cursor / VS Code / 任意终端都能跑。

## 它能做什么 / 不能做什么

| ✅ 会做                        | ❌ 不会做                 |
| --------------------------- | --------------------- |
| 逐节点击章节目录、加载视频               | 替你登录（账号/短信/扫码只有你本人有）  |
| 静音播放（`muted=true`），保证进度真实推进 | 自动答题、自动提交测验           |
| 每节播到 98%（默认）再切下一节             | 快进/拖进度条（平台不允许，且会被判无效） |
| 读平台自己的「已完成」标记，跳过看过的章节       | 阅读文档 / PPT 类任务点       |
| 播放暂停、进度停滞时自动重触发             | 处理人脸识别 / 验证码 / 弹窗确认   |
| 断点续播：从上次位置接着放，不重头来          | 绕过平台防作弊机制             |

> 脚本在**你自己已登录的浏览器**里操作，Cookie 与登录态天然保留，因此不需要也不应该把密码交给脚本。

## 适用性：哪些课程能用

**能用**：超星（chaoxing）系平台上、结构为「左侧章节目录 + 视频任务点」的课程 —— 毛概、电路、大学英语等绝大多数网课。

**需要人工补**：

- **章节测验 / 测试 / 作业** → 脚本按标题直接跳过，需要你自己做；
- **文档 / PPT 阅读**类任务点 → 脚本只处理 `<video>`，不处理阅读时长；
- **音频 / 直播** → 不适用；
- **带人脸识别 / 验证码抽查**的课程 → 中途会中断，需要你在场。

**不适用**：智慧树、中国大学 MOOC、学堂在线等非超星平台（DOM 完全不同）。

如果课程的章节目录结构被超星改版，脚本有两级兜底（`div.posCatalog_select` → 通用 `li`），但仍可能失效 —— 这时跑 `node diag.js` 看目录结构，再按需调整 `scanChapters` / `clickChapter`。

## 前置条件

1. **Node.js**（≥ 16）与**谷歌浏览器 Chrome**；
2. 安装依赖（仅一个包）：
   ```bash
   cd scripts && npm install playwright-core
   ```
3. 你本人已完成登录（见下）。
4. **电脑不能进入睡眠 / 待机**，否则 Chrome 与脚本都会被系统挂起，播放立即中断。

   - **仅熄屏（显示器关闭）不影响播放** —— 视频是静音的，屏幕黑着照样播；
   - 真正会中断的是**睡眠 / 待机（S0 连接待机 / S3）**；
   - Windows 上把「插电时自动待机」关掉（只影响交流电，电池行为不变）：
     ```bash
     powercfg /change standby-timeout-ac 0     # 0 = 永不休眠
     powercfg /q SCHEME_CURRENT SUB_SLEEP STANDBYIDLE   # 复核，AC 显示 0x00000000 即生效
     ```
   - 想还原：`powercfg /change standby-timeout-ac 15`。
   - 笔记本**合盖**通常也会进入待机，长时间挂机请接电源、别合盖。

## 快速开始

**1）以调试模式启动 Chrome（保留登录态）**

```powershell
powershell -ExecutionPolicy Bypass -File scripts\launch_chrome.ps1     # Windows
```

```bash
bash scripts/launch_chrome.sh                                          # macOS / Linux
```

脚本会先关掉当前 Chrome（登录信息在用户目录里，不会丢），再带 `--remote-debugging-port=9222` 用同一个用户配置重启；**若 9222 已在运行则直接复用，不会重启**。

**2）手动登录**（必须你本人）

在打开的 Chrome 里登录智慧珞珈 / 珞珈在线（学号+密码，或 APP 扫码）。

**3）进入课程学习页**

`https://aicenter.whu.edu.cn`（或从智慧珞珈点「珞珈在线」）→ 个人空间 → 课程 → 目标课程 → 「开始学习」。若弹出《在线学习诚信承诺书》，勾选后确认。**左侧章节目录展开**，随便点开一节让播放器加载出来，保持这个页面不要关。

**4）开跑**

```bash
cd scripts
node autoplay.js
```

它会打印「已跳过 N 节标记为「已完成」的章节」，然后从第一节没看过的开始连播。进度实时写入 `scripts/autoplay.log`。

## 命令参数

| 命令                               | 作用                           |
| -------------------------------- | ---------------------------- |
| `node autoplay.js`               | **默认**：跳过已完成，从第一节没看过的开始，一直连播 |
| `node autoplay.js --list`        | 只列出章节目录 + 完成状态，不播放（**排错首选**） |
| `node autoplay.js --start 3.2`   | 从 3.2 这一节开始（之后未完成的继续）        |
| `node autoplay.js --all`         | 不跳过已完成，从头全部重播                |
| `node autoplay.js --no-wait`     | 每节只播几秒，快速验证流程是否通             |
| `node autoplay.js --stop-at 98` | 每节播到 **98%** 才切下一节（**默认值**，即「只剩最后 2%」）；想更早切用 `--stop-at 90` |
| `node autoplay.js --max-min 240` | 最多连播 240 分钟就停（默认 300）        |
| `node autoplay.js --force`       | 忽略进程锁强制启动（确认没有别的实例在跑）        |
| `node diag.js`                   | 诊断：打印章节目录 + 当前播放器状态          |

**想停下**：结束那个 `node autoplay.js` 进程即可（锁文件会自动删）。**想继续**：再跑一次 `node autoplay.js`，已完成章节会自动跳过。

⚠️ **同一时间只允许一个实例**。脚本用 `scripts/autoplay.lock` 做进程锁；已有实例在跑时再启动会直接退出并提示，避免多个脚本抢同一个浏览器（那样会互相点章节，表现为「乱跳、卡住、进度不动」）。

## 原理：怎么判断「这节看没看过」

超星章节目录的真实结构：

```html
<div class="posCatalog_select" id="cur<knowledgeid>">
  <span class="posCatalog_name" onclick="getTeacherAjax(courseid,clazzid,knowledgeid)">…</span>
  <span class="icon_Completed prevTips"><span class="prevHoverTips">已完成</span></span>
</div>
```

- **有 `span.icon_Completed`**（悬停显示「已完成」）= 平台认定这一节已达标 → **跳过**；
- 只有 `span.jobUnfinishCount`（未完成任务点数）= 没看完 → 需要播；
- 事件挂在**内层 `span`** 上，`<li>` / 外层 div 没有任何 onclick → 点内层元素才有效；
- ⚠️ **不要用「断点续播位置」判断是否看过**：已完成的章节重新进入时 `currentTime` 可能只有几十秒，位置完全不可靠。`icon_Completed` 才是权威判据。

播放器是 **video.js**：切到新一节时 `<video class="vjs-tech">` 处于「封面 + 大播放按钮」态（`preload=none`、`readyState=0`、`videoWidth=0`），**必须点 `.vjs-big-play-button`** 才会加载。因此脚本绝不用 `videoWidth === 0` 判定「本节无视频」，而是用「`currentTime` 是否真的在推进」来确认播放成功。

## 排错

先跑 `node diag.js`，它会一次性打印**章节目录（含完成状态）**&#x548C;**当前播放器状态**。

| 现象                            | 原因 / 处理                                                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 连不上 9222                      | Chrome 不是调试模式启的，重跑 `launch_chrome.ps1` / `.sh`                                                               |
| 提示「已有 autoplay 实例在运行 (PID x)」 | 真有别的实例在跑，先结束它；确认不需要了就加 `--force`                                                                             |
| 未扫描到章节                        | 你不在课程【学习】页，或左侧目录没展开                                                                                          |
| 「未找到可点击的章节元素 [no-target…]」    | 超星改版，`div.posCatalog_select` / `span.posCatalog_name` 变了，跑 `diag.js` 看实际结构后改 `scanChapters` / `clickChapter` |
| 「本节无视频（测验/文档），跳过」但明明有视频       | 多半是播放器换了实现或没出现新的 `src`，用 `diag.js` 对比 `currentSrc` / `.vjs-big-play-button`                                  |
| 某节一直暂停                        | 脚本每 5 秒会自动重触发；仍不行手动点一下播放键，下一节会自动继续                                                                           |
| 进度长时间不动                       | 脚本有「停滞 >90s 自动重触发」的自愈逻辑；页面被手动切换过则重跑脚本                                                                        |

## 版本历史

**v1.3.1**

- 文档补充：**电脑进入睡眠 / 待机会中断播放**（Chrome 与 node 进程被系统挂起），前置条件里加了关闭「插电自动待机」的说明；仅熄屏不影响。

**v1.3.0**

- 切节阈值从写死的 90% 改为可配置，**默认 98%**（即「只剩最后 2% 不播」），新增 `--stop-at <百分比>`；
- 原因：实测发现**播到 90% 平台并不一定会记「已完成」**（3.1 / 3.3 / 3.4 / 3.5 都在 90% 处切走，重扫时仍未标记完成），需要更接近片尾才稳；
- 修复「**有视频却报无视频**」的误判：某节播放器 iframe 重载慢时，首次 30s 内等不到新 `src` 会被整节跳过（实测 3.2「新民主主义革命的对象」中过招，实际是有 548 秒视频的）。现在会**重新点击该节再等 45s**，仍等不到才判无视频。

**v1.2.0**

- 读章节目录的「已完成」标记，**默认跳过已完成章节**，直接从没看过的那节开始；
- 新增 `autoplay.lock` 进程锁，杜绝多实例抢同一个浏览器；
- 新增 `diag.js` 诊断脚本；`--list` 增加完成状态标注；
- 新增 `--all`（重播全部）/ `--force`（忽略锁）。

**v1.1.0**（修掉「装模作样」）

- ① 点击目标从 `<li>` 改为内层 `span.posCatalog_name`（原来点了等于没点，视频永不换节）；
- ② 播放方式改为「静音 → 点 `.vjs-big-play-button` → `play()` → 用 `currentTime` 推进确认」，不再拿 `videoWidth===0` 误判「无视频」；
- ③ 所有页面求值加超时（避免某个 iframe 卡死整个脚本）；进度停滞 >90s 自动重触发；
- ④ `frame.evaluate` 只能传一个参数，多字段须打包成对象。
